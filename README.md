# عقار درايف: بيتك الرقمي

ابنِ لي منصة عقارية رقمية كاملة اسمها "عقار درايف" (Aqar Drive)، مكتب عقاري سحابي بالكامل بدون فروع فعلية. المنصة تخدم السوق السعودي واللغة الأساسية عربي (RTL) مع دعم إنجليزي اختياري.

الهوية البصرية

الألوان: خلفية داكنة (near-black charcoal #101216)، أسطح #181B21 و#1E222A، لون مميز ذهبي/برونزي (#C9A961 وأفتح منه #E4CE96)، نص فاتح #F3F1EC، رمادي مكتوم للنصوص الثانوية #9AA0AC. ألوان الحالة: أخضر متاح #5FB88A، أصفر محجوز #E0A83E، أحمر مباع #D9695F.

الخطوط: عناوين بخط Cairo (وزن 700-900)، نصوص بخط Tajawal (وزن 400-500). كلاهما من Google Fonts.

الشعار: رمز هندسي بسيط (سقف بيت مبني من خطين متقاطعين بلونين مختلفين من الذهبي) داخل مربع بحواف مدورة خفيفة وحدود رفيعة.

الطابع العام: فخم وهادئ، مساحات بيضاء (سوداء هنا) كافية، بدون تدرجات لونية صاخبة، بدون بطاقات دائرية موحدة الشكل (Generic SaaS cards)، اعتماد على خطوط فاصلة رفيعة وتخطيط منظم.

الصفحات والميزات المطلوبة

1. الموقع التعريفي (Landing Page)

قسم رئيسي (Hero) بعنوان قوي يعكس فكرة "بلا فروع، بلا انتظار"

قسم مزايا (3 بطاقات): معاينة رقمية، تعاقد إلكتروني، دعم متواصل

قسم "كيف تعمل" بخطوات مرقّمة: بحث → معاينة عن بُعد → توثيق العرض → إنجاز العقد

دعوة نهائية للتسجيل/تصفح العقارات

2. خريطة العقارات (صفحة تصفح تفاعلية)

خريطة عقارية (استخدم Mapbox GL JS أو Leaflet + OpenStreetMap لخرائط حقيقية بإحداثيات GPS فعلية، وليست خريطة توضيحية مرسومة)

دبابيس (Pins) ملوّنة حسب حالة العقار (متاح/محجوز/مباع)

الضغط على أي دبوس يفتح بطاقة تفاصيل (اسم، سعر، حي، عدد غرف، مساحة، صور)

قائمة جانبية متزامنة مع الخريطة، فيها بحث وفلترة حسب الحالة والسعر ونوع العقار

زر "أضف عقارك": أي مستخدم مسجّل دخول يقدر يضيف عقاره (نموذج فيه: الاسم، الموقع على الخريطة، السعر، عدد الغرف، المساحة، الحالة، صور)، ويُحفظ بقاعدة بيانات حقيقية ويظهر فورًا لكل الزوار (Realtime)

3. لوحة تحكم الإدارة (Admin Dashboard)

نظرة عامة: مؤشرات (إجمالي العقارات، طلبات الشهر، صفقات مكتملة، إجمالي المبيعات) + رسم بياني لاتجاه المبيعات + رسم دائري لتوزيع حالة العقارات

إدارة العقارات: جدول فيه كل العقارات المضافة (من الإدارة ومن المستخدمين)، مع بحث وفلترة وإمكانية التعديل/الحذف/الموافقة على العقارات المضافة من المستخدمين قبل نشرها للعامة (Moderation)

طلبات العملاء: جدول متابعة طلبات التواصل/الحجز مع حالة كل طلب (جديد/قيد المتابعة/مكتمل)

تقارير: رسوم بيانية للمبيعات حسب المدينة/الحي ونوع العقار

4. نظام المستخدمين

تسجيل دخول/إنشاء حساب (بريد إلكتروني + كلمة مرور، أو ربط بجوجل)

أدوار: عميل عادي (يتصفح ويضيف عقاره)، مالك عقار، مدير (Admin) بصلاحيات كاملة على لوحة التحكم

كل عقار مربوط بحساب المستخدم اللي أضافه

البنية التقنية المطلوبة

الواجهة الأمامية: React + Tailwind CSS، تصميم متجاوب بالكامل (موبايل أولاً)، دعم RTL كامل

قاعدة البيانات والمصادقة: Supabase (Postgres + Auth + Realtime) — أنشئ الجداول التالية كحد أدنى:

properties: id, owner_id, name, district, city, price, beds, area, status (available/reserved/sold), lat, lng, images[], created_at

profiles: id, full_name, role (user/admin), phone

requests: id, property_id, client_id, status (new/in_progress/done), created_at, message

الخرائط: Mapbox GL JS أو Leaflet مع طبقة OpenStreetMap، بإحداثيات GPS حقيقية للمدن السعودية

الرسوم البيانية: Recharts أو Chart.js

الاستضافة: جهّز المشروع للنشر على Vercel أو Netlify، مع دعم ربط دومين مخصص لاحقًا

إدارة الكود: أنشئ المشروع بحيث يكون جاهز للرفع مباشرة على مستودع GitHub منظم (مجلدات واضحة: components, pages, lib, types)

ملاحظات مهمة

اكتب كل النصوص الظاهرة للمستخدم بالعربية الفصحى البسيطة، بدون ترجمة حرفية ركيكة

طبّق قواعد الأمان الأساسية بـ Supabase (Row Level Security) بحيث المستخدم العادي ما يقدر يعدّل أو يحذف عقارات غيره، والإدارة بس تقدر توافق/ترفض العقارات المضافة
